Como usar no GitHub Pages e entre celular e notebook

Esta versão pode ser publicada como index.html no GitHub Pages. A hospedagem entrega a página, mas não sincroniza os lançamentos: cada navegador guarda sua própria cópia local. Os dados de SR e MK são separados. Para passar os lançamentos do celular para o notebook (ou vice-versa), toque em “Backup JSON” num dispositivo e depois em “Importar JSON” no outro. Se duas pessoas editarem cópias diferentes, será preciso escolher qual arquivo importar; não existe sincronização automática entre dispositivos sem um serviço compartilhado.

No iPhone, o comportamento de armazenamento de arquivos HTML locais pode variar conforme o app usado para abri-los. Faça backups JSON regulares, especialmente antes de limpar dados do navegador.
